# 菜菜女仆配件实验室 · 项目总账

## v0.1.8（头部挂件水平跟随方向修正）

- v0.1.7 真机现象：女仆头部向右时，呆毛与耳鳍同步向左。两组都能稳定响应且方向一致，说明
  独立挂件修正已经执行，故障是 Ruby 头部参考 Part 的屏幕 X 增量与可见头部转向相反，并非
  未绑定、网格混组或左右耳再次绑反。
- 仅对呆毛和耳鳍的 Ruby 主模型头部姿势做“当前点相对中立点的 X 增量镜像”，Y 位移、缩放、
  旋转求解、Sen donor 自身姿势抵消和两组独立 projection 全部继续沿用。
- 尾巴复核结果：仍使用 `MAIN Part29→Part26` 与 `Sen Part93→Part83` 的身体双点框架，走直接
  方向且没有经过头部 X 修正；该路径在 v0.1.6 已保持成功，本轮不翻转、不改位置和原生摆动。
- 诊断中的 `attachment_groups` 明确标记头部两组为 `independent_head_frame_x_reflected`，尾巴为
  `independent_body_frame_direct`，便于下一次报告直接确认运行策略。
- 保留 v0.1.7 已确认的绑定零点、原生双耳九网格、呆毛六网格和三项配件选择列表。

## v0.1.7（三配件独立挂件绑定）

- 用户真机确认 v0.1.6 的网格拆分和显示均正确；新诊断确认呆毛严格为 6 个网格，耳鳍为
  原生左右两组共 9 个网格：`ParamL_angle` 命中右侧 3 个，`ParamR_angle` 命中左侧 6 个，
  `manual_mirror=false`，因此本轮不再修改耳鳍识别与绘制结构。
- 固化最新绑定零位：全局 `1.00/0.00/+0.20`；呆毛 `0.88/-0.03/-0.05`；耳鳍
  `1.24/-0.01/-0.29/整体+5°`；尾巴 `1.00/+0.02/-0.24`（在上一份位置上放大两次）。
- 呆毛、耳鳍、尾巴分别使用自己的过滤器、校准 projection、中立姿势记录和挂件修正调用。
  呆毛与耳鳍虽然都跟随 Ruby 头部框架，但不会共享 drawable filter，也不会生成或绘制组合组；
  呆毛弯曲、左右耳抖动和尾巴摆动仍由各自 Sen 原生网格/物理负责。
- `上一件/下一件` 从枚举全量轮换改为显式三项列表：尾巴 → 呆毛 → 耳鳍。原先第四项是
  `GLOBAL` 整体校准，并非隐藏网格；现已彻底退出配件选择和显示/隐藏操作。
- 诊断新增 `attachment_groups` 和 `calibration_cycle`，明确三组独立绑定且
  `combined_group=false`；若后续某一配件跟随异常，可单独判断而不会与另一头部配件混淆。

## v0.1.6（Sen 原生双耳与呆毛独立驱动）

- 复核 Sen 原项目后确认：原生渲染器只绘制完整模型一次，并没有“复制左耳生成右耳”的逻辑。
  旧版依据当前 X 坐标拆左右耳、再镜像绘制右耳，才是耳鳍间距和旋转失控的根因。
- 耳鳍改为运行时依次拨动 `ParamL_angle/ParamR_angle/ParamR_angle2`，比较可见网格变化，
  从已确认的 `Part113` 六个种子网格扩展出完整原生双耳组；整组每帧只绘制一次。
- 呆毛继续严格限定为 `ArtMesh151/160/189/190/191/192`，不再与耳鳍共用二次头部挂点矩阵；
  两者只接收 Ruby→Sen 的兼容头部参数，各自保留 Sen 内部的变形器和物理响应。
- 尾巴已经通过真机验证，继续保留独立的身体双锚点修正，不改动其网格、动作与默认位置。
- 废弃旧耳鳍镜像产生的对称旋转和间距值，启用新的校准存储键；保留用户最后确认的三组
  X/Y/缩放默认值和耳鳍整组 -10° 校正。
- 修正整体舞台矩阵的乘法顺序：在 projection 后追加同一 clip 变换，使主模型和每个过滤绘制
  使用同一最终缩放/位移，避免整体调整时相对距离被二次放大。
- 诊断升级为 `caicai-maid-accessory-calibration-v2`，新增每个耳鳍参数实际命中的 ArtMesh、
  `manual_mirror=false` 与单次原生双耳绘制模式，便于下一次真机报告精确核验。

## v0.1.5（挂件坐标层与整体缩放轴心修复）

- 真机结果：v0.1.4 尾巴挂件连接成功；呆毛与耳鳍在整体调整时发生大幅漂移，整个女仆模型
  连续缩放时向右下角移动。
- 判定无需再次拆分网格：尾巴成功、头部两组可独立隐藏且耳鳍动力正常，证明三组 drawable
  筛选已经独立。问题来自屏幕空间修正被放进模型投影层后，又经过不同模型的布局矩阵二次换算。
- 新增模型矩阵共轭换算：整体舞台、双锚点挂件、右耳镜像、耳鳍成对旋转与间距全部在最终
  OpenGL clip 坐标层生效，再安全换回各模型的 projection，避免位移和旋转被重复放大。
- 整体缩放轴心从 Live2D 画布原点改为女仆可见立绘中心；主模型与三个配件共用同一轴心，
  缩放时不应再持续向右下角游走。
- 1.0 倍、整体位移为 0 时不执行额外舞台矩阵，保持已经确认的静止校准与尾巴位置不变。
- 诊断新增 `attachment_transform_space=post_model_clip` 及整体缩放轴心 `pivot_x/pivot_y`。

## v0.1.4（三配件双锚点挂件）

- v0.1.3 真机确认耳鳍手动双抖恢复正常后，正式启用三配件动态挂件连接。
- 呆毛与耳鳍共用独立的头部双锚点框架；尾巴使用腰胯/上身双锚点框架。每帧从中立姿势计算
  女仆主模型的平移、旋转和缩放变化，不再只做中心点位移。
- 同时计算 Sen donor 自身的刚性头部/身体框架并将其抵消，避免两套不同 Live2D 参数响应
  叠加造成漂移；框架刻意不取耳鳍、呆毛或尾巴网格，因此耳鳍双抖、呆毛弯曲和尾巴摆动等
  配件内部物理不会被挂点修正抹掉。
- 已确认的 v0.1.2 静止位置继续作为绑定零位；挂件算法在零位为恒等变换，不重新改动用户校准。
- 整体缩放与移动仍先统一应用到主模型和三个配件，再在屏幕空间求挂点修正，防止缩放后漂移、
  消失或重复套用模型矩阵。
- 诊断字段 `attachment_mode` 更新为 `dynamic_two_point_anchor`，便于区分旧固定校准版本。

## v0.1.3（耳鳍独立动力恢复）

- 修复“快速抖动两次”被错误发送给女仆主模型的问题；`Part113` 和兔耳物理属于 Sen
  配件模型，事件现优先路由到 `overlayModel`。
- 修复配件专用更新分支没有推进耳抖计时、也没有在物理计算前准备
  `ParamL_angle/ParamR_angle/ParamR_angle2` 隔离输出的问题。
- 新增仅供配件层使用的最小耳鳍人格循环：不运行 Sen 的表情、身体、触屏或完整待机，只保留
  已确认的两次短脉冲；首次约 24 秒，之后每 28～68 秒低频自主触发，完全静止时暂停。
- 手动按钮与自主反应共用 Sen 已确认的 135%速度、100%幅度和隐藏九轴→独立物理路线。
- 固化 v0.1.2 新诊断位置为重置/干净导入默认值：全局 Y=+0.20；呆毛
  `0.88/-0.02/-0.05`；耳鳍 `1.14/+0.01/-0.29/旋转+8°/间距+0.22/整体-10°`；
  尾巴 `0.96/+0.02/-0.24`。升级安装继续保留已有自动保存值。
- 挂件连接继续延后到耳鳍手动双抖与低频自主反应通过实机确认之后，避免把动力故障和锚点故障
  混在同一轮判断。


## v0.1.2（呆毛/耳鳍硬隔离）

- 复核首轮诊断发现：父级名称虽正确，但 `Part13/Part220` 的递归结果额外夹带十个
  `texture_16` 耳类网格；它们在首轮静止诊断中透明，动作切换后可能显形并被套用呆毛校准，
  从而表现为耳鳍与呆毛合成一个部件。
- 呆毛停止递归 Part 层级，只允许已确认的六段长呆毛网格：
  `ArtMesh151/160/189/190/191/192`。固化根点仍为 `ArtMesh151`，继续保留 Sen 已确认的
  56%整体、100%长度、83%宽度、-49°与模型局部 X=-0.006。
- 耳鳍停止递归邻近头部层级，只允许 `Part113=兔耳` 对应六个网格：
  `ArtMesh631/1095/1021/146/629/1019`；右侧仍由这一组围绕中心轴镜像。
- 增加“单独测试：耳鳍快速抖动两次”，完全复用原 Sen 135%速度、100%幅度的隔离物理路线，
  只混回 `ParamL_angle/ParamR_angle/ParamR_angle2`。若处于完全静止，按钮会先退出静止。
- 本轮不要求新的位置诊断；先用隐藏/显示与耳鳍双抖确认两个配件已经彻底分离。


## v0.1.1（首轮真机修复）

- 修复主模型分前后层绘制时复用并污染投影矩阵的问题；该问题会让第二遍的前层头发重复套用
  模型变换，表现为头顶蓝块、左侧游离发丝，并可能在整体放大后离开裁剪区或黑屏。
- 配件校准位移随整体缩放同比变化，避免呆毛在默认倍率正确、整体缩放后发生相对漂移。
- 固化首轮诊断原始值：全局 `Y -0.01`；呆毛 `0.88 / X -0.02 / Y -0.05`；尾巴
  `0.82 / X 0.00 / Y 0.00`。最终合计位置分别为呆毛 `Y -0.06`、尾巴 `Y -0.01`。
- `Part113` 的六个耳鳍网格全部位于左侧，右侧并非遮挡而是没有独立网格。测试版现在以模型
  中心轴镜像左侧网格生成右耳鳍，左右共用原有物理结果，并继续支持对称旋转、间距和整体旋转。
- 暂停逐帧动态挂点差值修正，本轮使用固定校准变换验证显示、缩放与基础动作；诊断报告新增
  整体舞台变换、挂点模式和右耳鳍来源。

## v0.1.0（第一版测试版）

- 主模型：用户修改后的菜菜女仆；原服装、网格、物理和动作保留。
- Sen 动力层：当前使用完整编译 `.moc3`，只渲染呆毛、`Part113` 耳鳍和 `Part239`
  尾巴；其余 Sen 网格均不进入颜色绘制。
- `Part115` 兔耳结：默认排除；诊断报告单列其子网格，并报告选中配件的遮罩依赖。
- 私有包：单 ZIP + `accessory-lab.json`，App 只需一次导入。
- 贴图：主模型 4 张；Sen 只提供用户改色后的 slot 06/16/19。运行时按选中网格及遮罩依赖
  请求贴图，缺失依赖会提示并写进诊断清单。
- 图层：尾巴 → 主模型低层（含双马尾）→ 耳鳍 → 主模型高层 → 呆毛。
- 挂点：复制双方共有的头部、身体和呼吸参数；叠加主模型与配件模型的逐帧锚点位移差修正。
- 校准：三配件均有 X/Y/缩放/显示；耳鳍另有对称旋转、对称间距、成对中心轴旋转。
- 静止：暂停待机、测试运动、物理推进与点击反馈，作为位置诊断零点。
- 诊断：导出校准数值、配件网格、父 Part、贴图槽、遮罩源和 `Part115` 状态。
- 主模型交互：7 个互斥表情、7 个互斥动作；白袜/丝袜带子/双马尾/发带可独立切换；
  “变小”可与所有组叠加；点击预设仅在非静止状态触发。
- 袜子：默认黑袜，按钮初始显示“白袜”；切到白袜后按钮显示“黑袜”。
- 颜色：`ArtMesh122` 与 `ArtMesh149` 强制为 `#9E9EB2`；Sen 三配件使用用户已改色贴图，
  不叠加旧 Sen ArtMesh 色表。
